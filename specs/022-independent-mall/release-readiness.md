# 商城发布准备与投产门禁核对（T133）

更新：2026-11-09。状态：**证据差距初审已记录；T133进行中；当前不可投产或开放新购**。

## 当前结论

当前证据只支持商城代码和本地合成环境的阶段验收，不支持真实经营主体、商品准售、支付/退款渠道、发货、物流、开票或文件存储能力已就绪。应维持 `MALL_ENABLED=false`、`MALL_PURCHASE_ENABLED=false`、支付出站关闭、快递100 fake、商城存储出站关闭。该结论依据 [T131本地平台预检](platform-acceptance.md) 中读取的非敏感运行时开关；未读取密钥值，也未执行真实平台操作。

本文件是证据清点和阻塞登记，不是上线批准。T133仍依赖T063、T102、T131和T132等未完成任务；本轮只推进可离线完成的资料核对。

## 解除阻塞的证据顺序

1. 经营方确认销售/开票主体、准售SKU及资质、仓库和退货地址、配送范围/运费、售后负责人和可对外服务目标；财务确认税务资格、税目税率、开票/红冲渠道与真实金额口径。
2. 完成G-PROTOCOL与G-DATA所需的正式治理记录。仅有提案、一般隐私同意或本次“继续”均不构成宪章采纳或个人资料第三方交付授权；门禁解除后分别完成T048、T063、T102对应实现与验收。
3. 依G-LIVE逐项确认测试/生产环境、平台账户能力和操作范围；将秘密留在受控配置，不写入本文件。先验证隔离账号、测试订单、无个人信息对象和可用测试运单，再按明确授权核验真实平台结果。
4. 连接可运行当前小程序的iOS与Android微信设备，完成T132规定的状态/安全区/键盘/触控检查及5人选购观察；支付取消/未知仅通过隔离后端验证，真实资金操作必须另满足T131授权。
5. 完成所有故事级剩余任务及回归；再执行T134发布/回退运行手册评审和T135追踪核对。每一项只在实际证据通过后完成打勾。
