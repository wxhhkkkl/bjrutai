# 商城小程序参考图与设计边界

确认日期：2026-11-06。用户提供商品列表截图，并明确要求借鉴布局、不显示“综合”选项，视觉风格由实现方确定。截图原件保存在 [`design-assets/mall/user-product-list-reference-2026-11-06.png`](../../design-assets/mall/user-product-list-reference-2026-11-06.png)。

## 采用内容

- 商品浏览顺序采用“搜索框 → 横向排序/分类筛选 → 双列商品卡片”；有图时展示真实商品图，缺图时用中性图标占位，卡片还展示名称、当前售价和售罄状态。点击卡片进入商品详情。
- 分类筛选使用接口返回的启用分类；价格筛选使用接口支持的默认、价格升序和价格降序排序。价格控件循环切换升序/降序。
- 分类弹层位于自定义底部导航上方，预留 132rpx 导航高度及底部安全区，保证最后一个分类可见且可点击（2026-11-11，T037 / FR-017 遮挡修复）。
- 不显示“综合”tab。公开查询契约没有销量字段，因此不显示无效的“销量”排序。
- 商品规格有市场价时，在售价下方显示划线市场价；列表使用最低售价对应规格的市场价；商品图片使用服务端签名图片，缺图时只显示中性图标，不生成伪造商品图。
- 商品卡片右下角提供加购按钮：单规格直接加购，多规格进入详情选择；售罄时保留售罄标记。购物车入口固定在商城页面右下方、底部导航上方；商品详情提供加入购物车和立即购买。购物车、地址选择、确认订单和支付结果页面已经接入T051实现，支付结果必须回查服务端订单/支付状态。
- 购物车有商品时，导航栏与首张商品卡之间留 `30rpx`，留白随商品列表滚动（2026-11-12，T051 / FR-018）。

## 本项目采用的视觉风格

以健康零售为场景，采用温和、克制的自然色：暖灰米色页面底、松针绿交互色、陶土红价格色、白色信息卡。商品图片保持真实和突出；边框与阴影轻量，文字优先保证商品名、售价、库存的识别。双列布局、搜索和筛选层级参考用户截图，配色、卡片细节和交互状态由本项目重新设计。

## 页面状态与行为

- 商品列表：加载、空结果、权限拒绝、可恢复错误、翻页中及翻页失败可重试。
- 商品详情：加载、下架/不存在、权限拒绝、可恢复错误；所选规格的销售价、规格选中态、库存/售罄状态、商品介绍和使用说明按服务端数据呈现。
- 刷新和筛选变更会清空游标并从第一页重新查询；翻页失败保留已加载商品。
- 虚拟商品详情标明“后台人工交付”；结算隐藏收货地址并显示免运费。订单详情在交付前展示等待商家交付，完成后显示交付内容；后台订单详情提供仅有订单写权限时可用的纯文本交付表单，不显示快递表单。

## 本轮未覆盖

当前实现覆盖商品浏览、详情、购物车、地址、结算、支付结果、我的商城订单、订单详情、物流轨迹和售后申请/进度/退货运单。订单使用独立的状态筛选、订单卡片及详情时间线；物流页分别显示快递100轨迹来源、查询状态和本地发货事实，并明确物流签收、本地发货和买家确认收货各自独立。售后页使用流程表单、状态卡片和独立的退款/发票进度，不采用商品双列卡片布局。此参考图只覆盖商品列表的布局层级，不要求其他页面照搬商品卡片结构。商品及售后页面的真机视觉验收由用户于2026-11-10确认完成（详细设备/页面记录未归档）；US6完整开票流程继续按对应任务实现。

### 商品编辑弹窗调整

新增和编辑商品使用适中宽度弹窗（最大 1080px / 90vw），顶部留白并限制高度，不顶屏；页面不切换路由也不显示侧边栏。弹窗按「基础设置」「价格库存」「商品详情」分组；基础设置首项为“商品属性”单选（实物商品/虚拟商品，默认实物商品），商品名称、分类和主图为必填项。内容区采用独立边框容器，基础字段保持适中的表单宽度；主图和轮播图均使用约 150×150 的虚线加号上传框，已上传图片以相同尺寸预览，缩略图右上角使用删除图标，不显示图片序号或“移除”文案。窄屏时上传标签改为卡片上方排列。弹窗内容区独立滚动，底部操作保持可见。商品详情支持富文本，小程序展示格式；历史纯文本继续按原样显示。

- 商品编辑：价格库存使用规格表格，可直接添加规格，不切换单规格或多规格模式。规格表包含选填市场价、必填销售价、成本价、库存与预警数量；市场价只作参考，不参与订单结算。

### 2026-11-11 后台一级分类（FR-010 / T035）

分类列表取消父分类列；新增/编辑只展示名称、排序和状态。商品列表筛选及商品编辑的分类选项直接展示名称。保存分类固定parentId=null，接口拒绝非空父分类。保留历史分类和商品关联，历史子分类编辑保存后转为一级，不进行批量存量迁移。

### 2026-11-11 结算移除勾选确认

结算页移除“我已核对商品、金额和配送信息，并知晓支付与履约资料用途”勾选项。按用户后续要求移除结算页用途告知版本及支付/履约说明文案；点击“确认并提交订单”时仍记录支付与履约用途确认。

### 2026-11-11 商品卡片加购飞入动画

单规格商品卡片加购成功后，购物车图标从点击位置沿轻微弧线飞向右下角悬浮购物车，并刷新购物车数量；未登录、失败或售罄不播放成功动画。多规格商品仍先进入详情选择规格。

### 2026-11-11 商城筛选选中态主题色

价格排序、分类筛选入口、分类弹层当前选项文字及勾选标记统一使用全局选中色`#1677FF`，与底部导航选中态保持一致。

### 2026-11-11 结算订单备注输入框

订单备注标签单独一行；多行文本框置于下一行并占满卡片内容宽度，初始高度约两行文字，输入较多时自动增高。

### 2026-11-11 收货地址页字号调整

按用户提供的小程序截图放大地址页提示、空状态、地址信息、表单标题和字段、用途说明、同意确认、版本说明及操作按钮文字；提升表单行高和详细地址输入区高度以适配字号。

### 2026-11-11 售后进度页字号与商城主题色

按用户提供的售后进度截图提升正文、字段、状态辅助说明、金额行、提示和操作按钮的可读字号；商城交互主色统一为底部 Tab 选中态蓝色 `#1677FF`，覆盖链接、选择态、图标和主操作。保留退款金额及错误提示等语义色；遵循用户此前要求，购物车现有配色保持不变。其他商城页面中低于可读基线的辅助文字同步放大，字段/说明类文字至少 `24rpx`，页面主要内容至少 `26rpx`。

### 商品退货设置

商品基础设置默认支持退货，退货说明选填，最多 2000 字。小程序详情优先显示商品退货说明，留空时显示交易设置中的配送与退货说明。新订单保存商品退货设置，历史订单默认支持退货。关闭退货仅限制退货退款，符合售后条件的订单仍可申请仅退款。退货审核通过时按订单商品说明优先、交易设置兜底，说明不同时按商品分列。

### 2026-11-11 商品退货支持选项

商品编辑中“是否支持退货”标签与开关及两种状态文案在同一行展示。
