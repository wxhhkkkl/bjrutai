# 商城小程序参考图与设计边界

确认日期：2026-11-06。用户提供商品列表截图，并明确要求借鉴布局、不显示“综合”选项，视觉风格由实现方确定。截图原件保存在 [`design-assets/mall/user-product-list-reference-2026-11-06.png`](../../design-assets/mall/user-product-list-reference-2026-11-06.png)。

## 采用内容

- 商品浏览顺序采用“搜索框 → 横向排序/分类筛选 → 双列商品卡片”；有图时展示真实商品图，缺图时用中性图标占位，卡片还展示名称、当前售价和库存状态。点击卡片进入商品详情。
- 分类筛选使用接口返回的启用分类；价格筛选使用接口支持的默认、价格升序和价格降序排序。价格控件循环切换升序/降序。
- 不显示“综合”tab。公开查询契约没有销量字段，因此不显示无效的“销量”排序。
- 当前商品接口只提供售价，不提供划线原价。本版不显示虚构的原价或折扣；商品图片使用服务端签名图片，缺图时只显示中性图标，不生成伪造商品图。
- 商品卡片保留明确的购物车入口；商品详情提供加入购物车和立即购买。购物车、地址选择、确认订单和支付结果页面已经接入T051实现，支付结果必须回查服务端订单/支付状态。

## 本项目采用的视觉风格

以健康零售为场景，采用温和、克制的自然色：暖灰米色页面底、松针绿交互色、陶土红价格色、白色信息卡。商品图片保持真实和突出；边框与阴影轻量，文字优先保证商品名、售价、库存的识别。双列布局、搜索和筛选层级参考用户截图，配色、卡片细节和交互状态由本项目重新设计。

## 页面状态与行为

- 商品列表：加载、空结果、权限拒绝、可恢复错误、翻页中及翻页失败可重试。
- 商品详情：加载、下架/不存在、权限拒绝、可恢复错误；真实SKU价格、规格选中态、库存/售罄状态、商品介绍和使用说明按服务端数据呈现。
- 刷新和筛选变更会清空游标并从第一页重新查询；翻页失败保留已加载商品。

## 本轮未覆盖

当前实现覆盖商品浏览、详情、购物车、地址、结算、支付结果、我的商城订单、订单详情、物流轨迹和售后申请/进度/退货运单。订单使用独立的状态筛选、订单卡片及详情时间线；物流页分别显示快递100轨迹来源、查询状态和微信后台人工发货登记状态，并明确人工登记、物流签收、平台确认收货和本地确认收货各自独立；商城内人工登记回填已由T056实现。售后页使用流程表单、状态卡片和独立的退款/发票进度，不采用商品双列卡片布局。此参考图只覆盖商品列表的布局层级，不要求其他页面照搬商品卡片结构。商品及售后页面的真机视觉验收由用户于2026-11-10确认完成（详细设备/页面记录未归档）；US6完整开票流程继续按对应任务实现。
