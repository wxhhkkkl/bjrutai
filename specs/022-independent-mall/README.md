## 已确认边界

用户明确排除营销/统计/客服中心、商品品牌/属性管理/评论；商城消费纳入现有绩效；包含发票闭环；按二八原则完成收款到交付、退款、票据及核算链路。

现有绩效部分退款全额计入，因此未采用上版净额建议。商品款和运费分开、运费默认不计绩效、收货/售后期限等作为显式设计默认，不能误记为用户逐项批准。
