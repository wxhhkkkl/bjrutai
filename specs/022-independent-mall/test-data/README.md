# 商城商品目录合成测试数据 v1

数据文件：[mall-catalog-synthetic-v1.json](mall-catalog-synthetic-v1.json)。

- 共3个测试分类、6个虚构商品、7条商品规格，覆盖单规格可售、多规格混合库存、规格售罄、下架有库存、缺图草稿和资料不完整草稿。
- 商品名、规格记录标识、选填条形码和图片键均为合成值；图片键是占位符，不包含真实图片或COS对象。
- `specificationCode`和`barcode`均为测试值，不是实际商品条码或经营资料。`on_sale`仅用于隔离测试的商品列表/购买流程样例。
- 数据不得导入开发者工具体验版、生产环境或对客环境。`runtimeImportAllowed`固定为`false`；当前没有自动装载脚本，也没有写入任何数据库。
- 当前UI名称为“商品规格”；每条规格包含可选条形码、规格、市场价、成本价、库存和预警数量，以及必填销售价。市场价只作参考，不参与下单金额。若用于数据库或页面验收，须在独立隔离测试环境映射分类/图片ID；图片应使用测试对象，支付与物流保持fake。
