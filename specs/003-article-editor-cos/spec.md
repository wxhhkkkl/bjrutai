# Feature Specification: 文章管理增强 — 分类、富文本编辑器、COS上传、预览

**Feature Branch**: `003-article-editor-cos`  
**Created**: 2026-07-31  
**Status**: Draft  
**Input**: User description: "文章管理模块 文章管理需要有分类管理模块，文章关联不同的分类；文章编辑需要有成熟简单使用的文本编辑器 需要可以上传图片，并且图片使用腾讯云COS服务；文章提供预览功能"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 文章分类管理 (Priority: P1)

管理员可以创建、编辑、删除文章分类，每个分类有名称和排序序号。文章创建/编辑时可选择一个分类关联。分类列表按排序序号排列。

**Why this priority**: 分类是文章内容组织的基础，没有分类文章将无法归类，必须最先实现。

**Independent Test**: 进入分类管理页面 → 新建"政策解读"分类 → 在文章编辑中选择该分类 → 文章列表按分类筛选 → 删除未使用的分类 → 删除已关联文章的分类时收到提示。

**Acceptance Scenarios**:

1. **Given** 进入文章管理→分类管理，**When** 点击"新建分类"，输入名称和排序号并保存，**Then** 分类出现在列表中
2. **Given** 存在分类列表，**When** 编辑某个分类的名称或排序号并保存，**Then** 更新立即生效
3. **Given** 存在一个未被文章引用的分类，**When** 点击"删除"，**Then** 分类被移除
4. **Given** 存在一个已被文章引用的分类，**When** 点击"删除"，**Then** 提示"该分类下有 N 篇文章，无法删除"
5. **Given** 进入文章编辑页，**When** 查看分类下拉框，**Then** 看到所有可用分类

---

### User Story 2 - 富文本编辑器与COS图片上传 (Priority: P1)

文章编辑页面使用成熟的所见即所得编辑器，支持基本排版（加粗、斜体、标题、列表、链接），并可通过编辑器工具栏直接上传图片，图片自动存储到腾讯云COS并返回URL嵌入正文。

**Why this priority**: 文章内容是核心功能，文本编辑和图片上传是内容创作的基础需求。

**Independent Test**: 新建文章 → 在编辑器中输入排版文字 → 通过编辑器上传一张图片 → 图片出现在正文中 → 保存文章 → 重新打开编辑，图片仍然正常显示。

**Acceptance Scenarios**:

1. **Given** 进入文章新建/编辑页，**When** 查看内容区域，**Then** 显示富文本编辑器工具栏（标题、加粗、斜体、列表、链接、图片上传等）
2. **Given** 在编辑器中，**When** 点击图片上传按钮并选择本地图片，**Then** 图片上传至COS并自动插入正文光标位置
3. **Given** 编辑器中有图片，**When** 保存文章后重新打开，**Then** 图片正常显示且URL指向COS
4. **Given** 在编辑器中，**When** 尝试上传超过10MB的图片，**Then** 收到"图片大小不能超过10MB"的提示
5. **Given** 用户粘贴外部网页内容，**When** 粘贴到编辑器中，**Then** 保留基本格式但过滤危险标签（script等）

---

### User Story 3 - 文章预览 (Priority: P2)

管理员在编辑文章时可以点击"预览"按钮，在新标签页或弹窗中看到文章发布后的实际展示效果。

**Why this priority**: 预览确保发布前文章排版和图片显示符合预期，减少发布后修改。

**Independent Test**: 编辑一篇文章 → 点击"预览" → 在新窗口看到渲染后的文章内容 → 关闭预览继续编辑。

**Acceptance Scenarios**:

1. **Given** 在文章编辑页，**When** 点击"预览"按钮，**Then** 打开预览窗口，展示文章标题、分类、正文渲染效果
2. **Given** 在预览窗口，**When** 查看文章中的图片，**Then** 图片正常加载和显示
3. **Given** 在预览窗口，**When** 关闭预览，**Then** 回到编辑页面，编辑内容保留不变

---

### Edge Cases

- 上传非图片文件（如 PDF、视频）时，编辑器应拒绝并提示"仅支持 JPG/PNG/GIF/WebP 格式"
- 编辑器内容为空时，提示"请输入文章内容"
- 预览时文章标题为空、内容为空应有相应占位显示
- 分类删除操作需要二次确认弹窗
- COS上传失败时（网络错误、凭证过期），编辑器应显示明确的错误提示，图片不回退为base64内嵌

## Requirements *(mandatory)*

### Functional Requirements

**分类管理**:
- **FR-001**: 系统须提供文章分类管理页面（分类列表、新建、编辑、删除）
- **FR-002**: 每个分类须包含：名称（唯一）、排序序号、创建时间
- **FR-003**: 文章创建/编辑时须可选择关联一个分类
- **FR-004**: 文章列表须支持按分类筛选
- **FR-005**: 删除分类时须检查是否有关联文章，若有则拒绝并提示文章数量
- **FR-006**: 分类列表须按排序序号升序排列

**富文本编辑器**:
- **FR-007**: 文章编辑页须集成所见即所得富文本编辑器，支持标题（H1-H3）、加粗、斜体、无序/有序列表、超链接、图片上传
- **FR-008**: 编辑器工具栏须包含图片上传按钮，点击后选择本地文件
- **FR-009**: 图片上传须通过后端代理上传至腾讯云COS，前端不可直接持有COS凭证
- **FR-010**: 上传图片限制：格式 JPG/PNG/GIF/WebP，单张不超过 10MB
- **FR-011**: 上传成功后图片URL自动插入编辑器光标位置
- **FR-012**: 编辑器须过滤粘贴内容中的危险标签（script、iframe、on*事件属性）

**文章预览**:
- **FR-013**: 文章编辑页须提供"预览"按钮
- **FR-014**: 预览须在新标签页或弹窗中展示文章的实际渲染效果（标题、分类、正文）
- **FR-015**: 预览中的图片须正常加载显示

**COS上传**:
- **FR-016**: 后端须提供图片上传接口，接收文件后上传至腾讯云COS，返回COS公开URL
- **FR-017**: COS配置（SecretId、SecretKey、Bucket、Region）须使用环境变量，不可硬编码
- **FR-018**: 上传接口须验证文件类型和大小

### Key Entities

- **文章分类 (ArticleCategory)**: 名称（唯一）、排序序号、创建时间。一分类对多文章。
- **文章 (Article)**: 已有实体，新增 `category_id` 外键关联。已有字段：标题、摘要、正文（HTML）、状态、封面图、标签、版本号。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 管理员可在 30 秒内完成一个文章分类的创建
- **SC-002**: 图片上传从点击到插入编辑器耗时不超过 5 秒（正常网络下）
- **SC-003**: 预览窗口中文章排版和图片显示与发布后完全一致
- **SC-004**: 所有分类操作（新建、编辑、删除）均有明确的成功/失败反馈

## Assumptions

- 腾讯云COS Bucket 已创建且配置了公开读权限
- 富文本编辑器选用轻量级、中文友好的开源方案，集成方式为Vue组件
- 文章预览为新标签页打开，不需要复杂的权限校验（仅管理员可访问预览）
- 分类管理页面放在文章管理模块下，作为文章管理的子页面或Tab切换
- 图片上传由后端代理（前端→后端→COS），前端不直接操作COS SDK
- 已有后端COS配置项（COS_SECRET_ID, COS_SECRET_KEY, COS_BUCKET, COS_REGION）在.env中
