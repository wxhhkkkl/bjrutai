# 实施计划：小程序分享配置管理

## 技术方案

- 使用 FastAPI + SQLAlchemy 管理 `mini_program_share_configs`，`page_key` 唯一；新增版本化 Alembic migration，插入当前首页与绑定码分享默认值。
- 新增管理员列表/创建/更新接口与公开按页读取接口。来源选项从当前 `miniProgram/app.json` 注册页面中过滤得到，排除帮助与反馈、消息通知、隐私授权、法律文档、客户绑定、员工邀请、加入组织、客户绑定结果、账户信息、绑定记录、绑定结果、登录、完善资料、绑定微信和组织业绩；服务端校验来源页、已注册落地路由、重复配置、必填文案/图片及绑定码路径占位符。
- 管理端按已选第一版设计实现：清单表格 + 右侧编辑抽屉；抽屉展示来源页面、允许渠道、落地路径、分享内容、上传、好友/朋友圈卡片预览及保存状态。
- 复用 COS 图片上传模式，图片文件放在 `shares/` 前缀。
- 小程序新增分享配置服务与内存缓存；任意页面在加载时预取其分享配置，在同步分享回调中使用缓存配置并保留默认值回退。既有自定义回调的业务路径优先保留，好友卡片标题与图片使用配置值。
- 在推广码页面移除朋友圈分享入口与朋友圈回调；保留好友分享并按配置路径替换编码后的 `{refToken}`。
- 后台增加独立 `mini_program_shares.read/write` 权限，菜单和路由按权限显示。

## 数据/API 契约

- 管理端：`GET /api/v1/admin/share-configs` 返回现有配置、未配置来源页选项及有效落地路由。
- 管理端：`POST /api/v1/admin/share-configs` 新增一条配置，来源只能是当前注册且尚未配置的页面。
- 管理端：`PUT /api/v1/admin/share-configs/{page_key}` 更新一条既有配置，携带 `version` 做乐观并发校验。
- 小程序：`GET /api/v1/share-configs/{page_key}` 返回该页公开分享字段，不返回后台审计信息；`page_key` 为已注册路由的稳定 key。
- 更新字段：`friendTitle`, `friendImageUrl`, `landingPath`, 首页额外包含 `timelineTitle`、`timelineImageUrl`。
- 新增字段：`pageKey`；服务端通过当前已注册页面目录解析页面名和页面路径，客户端不得提交未注册来源页。

## 验证

- 运行后端格式/导入检查、管理端生产构建、小程序静态检查。
- 启动管理端并检查列表、编辑抽屉及分享卡片预览的视觉状态。
- 不触碰既有工作区中首页和患者绑定的未提交修改。
