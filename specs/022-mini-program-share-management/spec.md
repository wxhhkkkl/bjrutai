# 小程序分享配置管理

**状态：** 代码实现完成，待数据库迁移与真机验收
**输入：** 管理后台配置小程序分享内容，保留分享卡片预览。

## 范围

后台可为当前 `miniProgram/app.json` 中注册的可分享页面新增配置。帮助与反馈、消息通知、隐私授权、法律文档、客户绑定、员工邀请、加入组织、客户绑定结果、账户信息、绑定记录、绑定结果、登录、完善资料、绑定微信和组织业绩不提供来源配置。首页保留好友和朋友圈分享配置；客户绑定码保留好友分享与动态 `{refToken}` 路径。其他可分享页面默认使用好友分享配置；页面自身已有分享回调时，继续保留其动态路径和业务参数。

## 用户故事

### 管理员配置分享卡片（P1）

管理员在后台可查看、添加和编辑分享页面配置，从当前已注册但尚未配置的页面中选择来源。管理员可预览好友卡片；首页另可预览朋友圈卡片。每个来源页面只允许一份配置，关键字段不能为空。

**验收场景**

1. 已登录并拥有分享配置权限的管理员可查看已有配置，并从未配置的已注册页面中新增分享来源。
2. 管理员编辑标题、图片或落地路径并保存后，列表和小程序公开配置接口返回新值。
3. 两个分享卡片预览显示页面名称、标题、卡片图片及小程序入口样式。
4. 客户绑定码预览和实际转发只有好友渠道，路径保留 `{refToken}` 并在运行时替换成该客户顾问的 token。
5. 可分享来源从当前 `miniProgram/app.json` 页面中筛选；帮助与反馈、消息通知、隐私授权、法律文档、客户绑定、员工邀请、加入组织、客户绑定结果、账户信息、绑定记录、绑定结果、登录、完善资料、绑定微信和组织业绩不出现在新增选项中；已经配置的页面不重复出现。
6. 页面已有自定义分享回调时，配置标题和图片生效，原有动态路径和业务参数保持有效。

### 小程序应用分享配置（P1）

所有已配置页面读取其分享配置并应用到分享回调。配置接口不可用时使用当前页面已有默认分享内容，不能阻断页面使用或改变业务行为。

## 需求

- **FR-001**：每个分享来源页面必须至多有一条配置；初始数据包含首页和客户绑定码两条配置。
- **FR-002**：后台可从当前 `miniProgram/app.json` 中允许配置的页面新增来源；帮助与反馈、消息通知、隐私授权、法律文档、客户绑定、员工邀请、加入组织、客户绑定结果、账户信息、绑定记录、绑定结果、登录、完善资料、绑定微信和组织业绩必须排除；已配置来源从新增选项中移除。
- **FR-003**：每条配置的好友标题、好友卡片图片和落地路径均必填；首页另必填朋友圈标题和图片。
- **FR-004**：客户绑定码只支持好友分享，路径固定指向客户绑定页且包含 `{refToken}` 占位符；已有自定义分享回调的页面保留回调生成的路径和参数。
- **FR-005**：所有落地路径必须指向 `miniProgram/app.json` 注册的页面；路径不能为空。
- **FR-010**：落地页面选项排除绑定结果、登录、完善资料、绑定微信、组织业绩、个人业绩、功能占位页和入口页；服务端同时拒绝保存这些路径。
- **FR-006**：分享图片通过后台上传至 COS；地址只读显示，上传后可点击缩略图放大预览。
- **FR-007**：后台读取和写入需要管理员对应权限；小程序通过公开只读接口读取分享配置。
- **FR-008**：保存失败或读取配置失败时，小程序继续使用当前默认分享行为；绑定码 token 按 URL 编码保留。
- **FR-009**：客户绑定码页面隐藏朋友圈入口；首页支持好友和朋友圈分享，其他已配置页面支持好友分享。
- **FR-011**：新增分享来源只能是当前已注册且未排除的页面；服务端校验来源路由和重复配置，新增与更新均要求分享配置写权限。

## 非目标

- 不改变员工邀请的个人化分享路径和二维码。
- 不修改现有客户绑定、登录和授权逻辑。
