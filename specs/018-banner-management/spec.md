# Feature Specification: 首页轮播图管理

**Feature Branch**: `018-banner-management`  
**Created**: 2026-09-14  
**Status**: Ready for implementation  
**Input**: 为管理后台增加轮播图管理，并在小程序首页展示。

## User Scenarios & Testing

### User Story 1 - 管理首页轮播图 (Priority: P1)

管理员可以上传一张轮播图、填写识别标题、设置展示顺序和跳转方式，并控制其是否在小程序首页展示。

**Acceptance Scenarios**:

1. **Given** 管理员已登录，**When** 新建并启用一张包含有效图片的轮播图，**Then** 后台列表显示该项目，且小程序公开接口返回它。
2. **Given** 管理员编辑轮播图的图片、标题、排序或跳转文章，**When** 保存成功，**Then** 后续首页请求得到更新后的内容。
3. **Given** 管理员停用或删除轮播图，**When** 小程序重新进入首页，**Then** 该项目不再出现。

### User Story 2 - 首页浏览轮播图 (Priority: P1)

小程序用户在首页顶部可浏览后台配置的已启用轮播图；关联文章的轮播图可进入对应文章详情。

**Acceptance Scenarios**:

1. **Given** 存在多个已启用轮播图，**When** 用户进入首页，**Then** 按排序从小到大显示可左右滑动的轮播图及位置指示点。
2. **Given** 轮播图配置为文章跳转且文章 ID 有效，**When** 用户点击轮播图，**Then** 小程序打开文章详情页。
3. **Given** 没有已启用轮播图或轮播图接口临时失败，**When** 用户进入首页，**Then** 首页其余工作台功能正常使用，且不显示空白占位卡片。

### User Story 3 - 浏览健康首页内容 (Priority: P1)

小程序用户进入首页后，浏览儒泰介绍与心脑维养主题内容，而不是业务快捷入口和数据概览。

**Acceptance Scenarios**:

1. **Given** 用户进入首页，**When** 页面加载完成，**Then** 首页按「轮播视觉、心脑维养专题、健康资讯、关于儒泰故事」的层次展示内容。
2. **Given** 用户浏览首页，**When** 页面内容或轮播图接口不可用，**Then** 已加载的其他内容保持可用，页面不因工作台指标接口失败而进入错误状态。
3. **Given** 用户希望继续阅读健康内容，**When** 点击心脑维养板块的资讯入口，**Then** 小程序进入现有文章资讯列表。
4. **Given** 各自分类下有多篇已发布文章，**When** 用户浏览「心脑维养」或首页底部的「关于儒泰」，**Then** 每个栏目按发布时间展示最多三篇内容：一篇重点内容和两篇补充内容；点击任意内容均打开对应文章详情。

## Requirements

- **FR-001**: 轮播图记录必须包含图片 URL、可选标题、排序值、状态、跳转类型和可选文章 ID。
- **FR-002**: 后台管理接口仅允许管理员访问；公开读取接口不要求小程序登录态，且只返回已启用记录。
- **FR-003**: 图片 URL 必须为 HTTP(S) URL；上传仅接受 JPEG、PNG、GIF 或 WebP，且单文件不超过 10 MB。
- **FR-004**: 新建轮播图默认停用；启用、停用、删除都必须在后台明确触发。
- **FR-005**: 仅支持「不跳转」和「跳转文章」两种动作；跳转文章时管理端必须以下拉列表选择已发布文章，并提交对应的文章 ID。
- **FR-006**: 小程序的轮播图请求必须与工作台、文章请求隔离，不能因失败使首页进入整体错误状态。
- **FR-007**: 管理端编辑使用版本号避免覆盖其他管理员已保存的内容。
- **FR-008**: 首页必须移除「快捷服务」和「业务概览」模块，以及它们的工作台数据请求。
- **FR-009**: 首页应按轮播图、心脑维养、健康资讯、关于儒泰的内容层次组织；心脑维养板块必须提供进入文章资讯的入口。
- **FR-010**: 关于儒泰板块位于健康资讯之后；它读取分类为「关于儒泰」的最新三篇已发布文章，第一篇使用企业封面视觉，其余两篇作为补充入口；三篇均跳转到各自文章详情。健康资讯列表不展示该企业介绍分类文章；其他已发布健康文章（包括心脑维养）可继续作为资讯展示，避免在普通资讯为空时产生大块空白。
- **FR-011**: 关于儒泰重点文章必须使用企业封面视觉，封面上展示文章标题、描述与进入提示；用户点击整张卡片进入对应文章详情。
- **FR-012**: 首页栏目标题仅使用中文展示，不显示英文眉标或英文栏目名称。
- **FR-013**: 首页采用明亮、现代的健康服务信息布局：轮播承担服务视觉主图；心脑维养采用一张重点大图与两张轻量补充卡片；健康资讯采用三条紧凑文章列表；关于儒泰以深色企业故事区收尾，包含一张重点企业封面和两条补充入口。不得以连续同质白色圆角卡片作为主要布局。

## Success Criteria

- **SC-001**: 已启用轮播图能在首页下一次显示时按预期排序展示。
- **SC-002**: 停用或删除后，公开接口不再返回对应轮播图。
- **SC-003**: 首页在轮播图为空、加载失败和图片加载失败时仍可浏览工作台与文章资讯。
- **SC-004**: 首页不再向工作台接口请求快捷服务或业务概览所需的数据。
- **SC-005**: 关于儒泰企业封面在首页以完整横向卡片展示，描述保持可读且不遮挡封面主体；心脑维养和关于儒泰均最多展示三篇来自各自文章分类的内容。
