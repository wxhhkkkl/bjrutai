# 商城小程序风格约定

- 来源：2026-11-06用户提供的商品列表截图 [`user-product-list-reference-2026-11-06.png`](user-product-list-reference-2026-11-06.png)；用户指定借鉴布局，去掉“综合”tab，视觉风格由实现方确定。
- 布局：搜索框在上、价格排序和分类筛选在下一行、商品使用双列图片卡片；卡片打开商品详情。
- 色彩：页面暖灰米色，操作与选中使用松针绿（`#27645B`），价格使用陶土红（`#BD563F`），内容卡使用白色。
- 数据：图片、售价、SKU、库存、分类均取商城服务端。当前契约不含销量和原价，不渲染销量排序或划线原价。
- 状态：覆盖加载、空、权限、错误、售罄和分页失败；购车和交易动作等购物车页面完成后再显示。
- 覆盖范围：当前商城浏览页和商品详情；其他商城页面沿用色彩与信息清晰度约定，按各自流程设计结构。
